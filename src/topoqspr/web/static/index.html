TopoQSPR

An Open-Source Web Tool for Disease-Anchored QSPR with Verified Topological Indices

TopoQSPR is an open-source, web-based tool that computes 104 verified degree-, reverse-degree-, neighbourhood-degree-sum-, distance- and matching-based topological indices and 91 bond-wise entropy measures for molecular and general graphs, and turns a disease name into a reproducible QSPR study: a controlled drug set from ChEMBL, reviewed before any computation, evaluated against molecular-size and composition baselines with leakage-free cross-validation. It supports six input methods, four tailored for chemistry and two for general graph analysis.

Exploratory mode. This site runs a fast, reduced analysis. Confirmatory analyses use the command-line protocol.

Molecules are standardised exactly as in the study (parent structure, hydrogen-suppressed graph); adjacency input is treated as an abstract graph. Every undefined value is reported with its reason, never as 0.

      Detailed Instructions

      TopoQSPR is a web-based computational tool that calculates verified topological indices and bond-wise entropies for chemical and general graphs, and runs disease-anchored QSPR studies with explicit baselines.

      1. Input files

      • SMILES: one structure per line, optionally followed by a name; or a CSV with a smiles column.
      • Molecular Data File (.mol) and SDF: chemical graphs; multi-record SDF files are supported.
      • Protein Data Bank (.pdb): structures from the RCSB PDB; hydrogens are suppressed.
      • Adjacency matrix: a square 0/1 matrix, as JSON (A = [[0,1],[1,0]]) or whitespace rows.
      • Adjacency list: JSON ({"1": [2, 3], ...}) or lines 1: 2 3.

      2. Work flow with TopoQSPR

      • Indices only: choose a format, paste or load structures, then Show indices (on-page table with structure depictions and edge partitions) or Download all (zip with every value, every reason for an undefined value, and the index catalogue).
      • Disease-anchored study: search a MeSH heading; build and review the drug manifest (every exclusion with its reason) before anything is computed; choose computed or measured targets; run. Results show the baseline ladder (null, size, composition, indices, RDKit 2D) with paired ΔR² and ΔMAE, confidence intervals and applicability-domain coverage, plus a downloadable run record.
      • Index catalogue: formula and primary reference for every index and entropy.
