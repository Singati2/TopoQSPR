# Advik Recommendations for TopoQSPR

**Date:** October 3, 2026

This document records Advik's feedback and recommendations on the current TopoQSPR project direction.

## Feedback

> "TOPOqspr progress so far is amazing."

1. **Per-disease analysis**
   - Agrees with the proposed approach for per-disease analysis.

2. **Endpoints**
   - The proposed endpoints sound good.
   - Endpoints can be changed later if needed.

3. **Thresholds / filtering decision**
   - No specific recommendation provided yet.

4. **Replication-study selection**
   - Not sure yet which studies should be selected.

5. **Study prioritization**
   - Consider the studies that show the best possible results.

6. **Licensing and repository visibility**
   - Full flexibility is granted to change the licensing.
   - The repository may be made public or private as appropriate.

7. **Paper format and writing style**
   - The paper should follow the format and writing style of the **ChemGraphX paper by Arockiaraj** as closely as appropriate.
   - The paper can be written after confirming that the website works reliably and that the corresponding GitHub code is accurate.

## Additional recommendation

Before the next update, carefully proof-check the definitions of the topological indices against other published papers, especially indices based on **reverse degree** and **neighborhood sum** definitions.

## Practical implications for the project

- Keep the per-disease analysis plan.
- Proceed with the currently proposed measured endpoints, while retaining flexibility to revise them later.
- Do not freeze the replication-study shortlist until the strongest scientifically defensible studies are identified.
- Verify every implemented topological-index definition against the literature before finalizing results.
- Prioritize website reliability and code correctness before drafting the final manuscript.
- Use ChemGraphX as a structural and stylistic reference for the manuscript, without copying text.
- Finalize the repository license and visibility based on the needs of publication and collaboration.
