# The TopoQSPR article against the ChemGraphX article: direct comparison

Reference: Jacob, Clement, Arockiaraj, Jindal, *ChemGraphX: an open-source web tool for computing
topological indices and entropy measures*, J. Cheminform. 18:39 (2026), doi:10.1186/s13321-025-01141-x,
PMC13020044 (open access; facts below were read from the Europe PMC full text on 2026-10-06).
TopoQSPR: `paper/main.tex` + `paper/supplement.tex` as of commit on 2026-10-06 (33 + 14 pages).

The goal set on 2026-10-04 was "paper better than ChemGraphX". "Better" is read as: more verifiable
claims, stronger validation, real experiments with pre-specified statistics, and everything
regenerable. The two articles have different scientific objects (a calculator versus a study
workflow), so the table compares what each article *demonstrates*, not what each tool is for.

| Criterion | ChemGraphX article | TopoQSPR article | Evidence for the TopoQSPR side |
|---|---|---|---|
| Scientific question | none stated beyond "compute indices efficiently"; QSPR potential discussed | one question, pre-registered: what do topological indices add beyond molecular size and composition on curated, leakage-free data? Answered on 1,821 approved drugs, 4 measured endpoints | `docs/EXPERIMENT_PLAN.md` (tag `plan-freeze-v1`), Table 5, Fig. 4 |
| Indices and entropies | 52 degree + 24 distance indices, 52 + 21 entropies (150 values) | 104 indices (6 families incl. reverse-degree R_k, hybrids, exact Hosoya Z), 91 entropies; every index registered with formula, primary source and tests | Table 2, Supplementary Table S1 (generated from the registry) |
| Index validation | 4 structures (TiO₂(3,5), two nanocones, FeS₂(2,2)) against published closed forms; "close agreement", with two Wiener/Szeged discrepancies attributed to the literature | six routes per index: closed forms on 4 graph families, brute-force enumeration, networkx, Mordred (6 shared), ChemGraphX itself (41 shared indices, 1,763 values, all agree; 1,414 entropy values agree to 8e-16), printed values of the primary papers; plus an independent check against 7 papers of other groups (199 test cases) that classifies every discrepancy and finds printed errors in 5 of them | §2.2, `docs/INDEX_VERIFICATION.md`, `docs/CHEMGRAPHX_CROSSCHECK.md`, `docs/LITERATURE_VALUE_CHECK.md`, `tests/` |
| Input formats | .pdb, .mol, adjacency list/matrix | the same four, plus SMILES, SDF, batch lists, and disease → ChEMBL drug cohort with manifest | §2.1, Fig. 3 |
| Related-tools comparison | Table 1: Dragon, PaDEL, CDL, GAP/MATLAB, TopoChemie-2020, Hayat et al.; speed on one zeolite framework | Table 3: Mordred, ChemGraphX, DOPtools, QSPRpred, RANQSAR, QSAR-in-the-Browser; six capability criteria, every cell checked against the tool's paper or documentation, with the one abstract-only row footnoted | §3 |
| Statistical evaluation | none (no models, CV, baselines or significance tests) | repeated nested CV with grouped folds, baseline ladder (null, size, composition, RDKit 2D), paired ΔR² with corrected repeated k-fold t intervals, BH and BY control, Y-randomisation, whole-procedure bootstrap, scaffold-grouped CV, applicability domain | §2.3, Tables 4–7, 10 |
| Experiments on real data | none (illustrative frameworks) | A: cohort sensitivity on 4 diseases; B: confirmatory family on 4 endpoints + scaffold and family ladders; C: optimism chain (training → v0.x CV → nested → scaffold) on 4 endpoints; D: replication of 3 published 2026 studies on their own data | §4, Tables 4–10, Figs. 4–7 |
| Negative results reported | none | three of four endpoints show no corrected-significant gain; a pre-specified control learner failed by extrapolation and is reported with its cause; published R² values collapse under nested CV | §4.2 Controls, §4.2 Experiment D |
| Reproducibility of the article's numbers | timings and validation numbers typed in the text | every number, table and figure is generated by `tools/make_*.py` from result files; run records with commit, versions, ChEMBL release, config hash, seeds; `topoqspr rerun` re-executes a run record and compares byte for byte; plan frozen and amended with dates | §2.4, `results/exp{A,B,C,D}`, `docs/EXPERIMENT_PLAN.md` |
| Preregistration | no | frozen plan with 5 recorded checkpoint decisions and dated amendments (OSF registration pending the authors' account) | `docs/CHECKPOINT.md` |
| Figures / tables | 10 figures (3 are screenshots of third-party software for file preparation), 2 tables | 7 figures, 11 tables in the main text; 1 long table + 2 tables in the supplement; all result figures generated | `paper/` |
| Tests and CI | none found in the repository | 1,101 offline tests (incl. 36 web, 199 literature, 93 replication-data), CI | `tests/`, `.github/workflows` |
| Reporting standards | — | OECD principles mapped to artefacts (S2), ML-in-chemistry checklist (S3), data licences stated per source | `paper/supplement.tex` |
| Limitations stated | server RAM limits graph size | no feature attribution yet; distance entropies not implemented; learned representations deliberately not benchmarked; controls with the full `selected` learner infeasible (stated with the cost) | §5 |

What ChemGraphX's article does that ours does not: it reports wall-clock speed on a very large
framework (SOD(6,6,1), 0.15 s for all distance indices) and targets graphs far larger than drug
molecules; TopoQSPR's web interface measures 0.1–0.2 s per drug-sized molecule (191 values) but
has not been benchmarked on nanostructures, and its distance entropies are missing. These are
stated in the article's limitations.

Verdict (lead author, 2026-10-06): on every criterion that concerns verifiable content, validation,
statistics, experiments and regenerability, the TopoQSPR article demonstrates more and documents it;
the comparison is reproducible from the files cited in the last column.
